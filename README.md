# Touch+-on-Quest-2
Magisk module that implements Touch+ controller pairing and tracking on a Quest 2

NEW REPO https://github.com/Noculus-VR/Q3-touch-on-Quest-2

Shout out to @nikitas_vrmodding on TikTok for being the first recorded user of this project

 # Instructions

 1.  Root your headset with Singularity
 2. Download and push module to Quest 2 
 3. In singularity-Magisk install the module and reboot
 4. In the Meta Horizon App unpair your Quest 2 controllers 
 5. Then navigating using either hand tracking or head tracking go to Settings -> Devices -> Controllers and pair the Touch+ controllers

### Your done

## MAKE SURE TO DISCONNECT TOUCH+ CONTROLLERS AFTER RESTART UNTILL  ROOTED OR FACE UNEXPLORED ISSUES
